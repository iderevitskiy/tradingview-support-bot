# AI-ассистент поддержки TradingView — тестовое задание

Всё решение в одном ноутбуке: [notebook.ipynb](notebook.ipynb) — анализ данных, архитектура, прототип,
оценка качества, метрики и мониторинг, развитие системы (задача 2), журнал решений (раздел 9).

## Запуск

```bash
python3.12 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/jupyter lab notebook.ipynb
```

- Выгрузка базы знаний в репозиторий не входит: положите её в `data/knowledge_base.csv`.
- Ключ Anthropic: переменная `ANTHROPIC_API_KEY` или файл `.secrets/anthropic.key`.
- Ответы моделей, эмбеддинги и результаты переранжирования кешируются в `cache/` (в репозиторий не входит,
  потому что содержит тексты базы). С кешем повторный запуск идёт без обращений к API и воспроизводит
  те же числа; первый полный прогон стоит порядка $10.
- Локальные модели (bge-base, bge-reranker-base) считаются на CPU в 4 потока; при первом запуске
  скачиваются с Hugging Face (~1,5 ГБ).

## Файлы

- `notebook.ipynb` — сдаваемый ноутбук с результатами выполнения.
- `src/notebook_src.py` — исходник ноутбука, ячейки разделены `# %%`.
  Сборка и прогон: `.venv/bin/python src/build_notebook.py --run`.
- `src/ablation.py` — пересчёт вариантов базы для журнала решений (`python src/ablation.py images`).
  Набор доработок задаёт переменная `KB_FEATURES` (по умолчанию `images,headings,tickets,rewrite`).
- `data/knowledge_base.csv` — выгрузка базы знаний (не в репозитории).
- `cache/` — кеш вызовов моделей и эмбеддингов (не в репозитории).
